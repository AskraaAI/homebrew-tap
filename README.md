# AskraaAI Homebrew tap

Homebrew casks for apps made by [Askraa](https://askraa.ai).

## RunnerVision

A free menu bar app for Mac that shows your self-hosted GitHub Actions runners on Colima.

```sh
brew install --cask askraaai/tap/runnervision
```

More at [runnervision.askraa.ai](https://runnervision.askraa.ai).
